# D3 — "Door"

**Lens: the oven's front.** The June oven is one black glass door. It has a window into the cavity and a small portrait screen set into the same glass (r1 §1 "Physical frame"; reference photos 01/02, `ic_oven_full_*`).

**Idea (one paragraph).** The card is that door, reduced to its two openings. The card background is the **pane**: one sheet of dark glass. The **window** is a 4:3 opening in the top-left of the pane, and the camera still sits in it exactly, never cropped. The **screen** is an inset panel on the right that holds everything the oven's own screen holds: the status word, one huge thin numeral, two short lines, and Stop. Because the camera has a place of its own in the object, it never has to be squeezed next to something, framed by a ring, or turned into the hero.

The metaphor removes elements instead of adding them. There is no header bar, no tab row, no mode icon and no separate camera tile. The oven's name sits under the window, like a nameplate on the door. The only other control is the quick-add group, which also sits under the window, on the food side of the door, so it stays well away from Stop on the oven side. When the oven is off the camera is off and the window has nothing to show. It shrinks to a small dark pane at top-left, and the glass shows the oven's home screen (clock, date, glowing-element tiles) across its full width. When a cook starts, the window opens up.

## 2. Layout per size

HA grid: height = rows × 56 + (rows − 1) × 8. All inner measurements are computed from the card box with CSS container queries (`container-type:size`, `cqw`/`cqh` units, `min-height:0`), so nothing depends on the content happening to be short.

### Standard — 12 × 5 (312 px tall)

```
┌──────────────────────────────────────────────┐   pane (dark glass)
│ ┌───────────────────┐ ┌────────────────────┐ │
│ │                   │ │    ● COOKING       │ │
│ │   WINDOW  4:3     │ │                    │ │
│ │  (camera still)   │ │     12:30          │ │   hero, Barlow Condensed Light
│ │                   │ │  left · done 6:42  │ │
│ └───────────────────┘ │   ━━━━━━──────     │ │   draining rule
│ Kitchen        ● Live │ Convection bake 400°│ │
│ [+1 ][+5 ][+10]       │ Food 128° of 145°  │ │
│                       │  [ ■  Stop ]       │ │
│                       └────────────────────┘ │
└──────────────────────────────────────────────┘
```

- Pane padding 12, column gap 14. Window column width = `min((W − gap)/2, (H − caption − chips − gaps) × 4/3)`, so the window is exactly as big as the box allows and never taller than the box. The screen panel takes the rest of the width.

| | 358 px section | 500 px section |
|---|---|---|
| Card | 358 × 312 | 500 × 312 |
| Window (camera) | 160 × 120 | 231 × 173 |
| Screen panel | 160 × 288 | 231 × 288 |
| Hero numeral | 56 px (width-bound, 41 cqw) | 85 px |
| Chips | 3 × 49 × 48 | 3 × 56 × 48 |
| Stop | 136 × 48 | 160 × 48 |
| Chip-to-Stop clearance | ≈ 30 px across the column gap and 26 px vertical offset | ≥ 90 px |

- The window group (window, nameplate, chips) is top-aligned with the screen panel. At 358 px this leaves dark glass below the chips, bottom-left. That is deliberate: it is the door's lower glass, and it balances Stop in the lower right, where the oven's own screen sits.
- **Off** (same box): a header row with the 64 × 48 camera-off window, the name and ○ OFF. Below it, a centred clock (44 px) and date, then one row of 5 tiles (60 × 52 at 358 px, 89 × 77 at 500 px) and a ‹ • • • › row made of five 48 × 48 buttons.

### Wall tablet — 24 × 8, spanning 2 section columns (1032 × 504)

The same door, larger. Pane padding 24, gap 24. Window 451 × 338, derived from height, so the screen panel gets the extra width: 509 × 456. Hero numeral **150 px** (capped; the brief asks for 110–150). Status 22 px, lines 24 px, chips 3 × 104 × 64 labelled "+1 min", Stop 260 × 64.

**The wall adds no layer.** It only scales, and when the oven is off it dims to 82 % (SHOULD "dim idle wall panels"). Off at wall size: an 80 px camera-off window, a 112 px clock, and 5 tiles per page at 125 × 108. The pages are the same as on the phone, so the tiles keep their spatial memory. Status text is 22 px at 2.5 m, about 15 mm cap height on a 10" tablet at this scale. That should be checked on the real tablet (r2 §2 "2–3 m test").

### Compact — 12 × 1 (56 px)

```
┌──────────────────────────────────────────────┐
│ [▣]   12:30   ● COOKING            [■ Stop]  │
│ Live          Kitchen · done 6:42 PM          │
└──────────────────────────────────────────────┘
```

A thumbnail column 52 px wide: a 44 × 33 window with its age label (10.5 px) underneath, so even the smallest size carries the camera with its age. Then the hero (32 px), two text lines, and Stop (48 × 48 minimum) while heating. Chips are dropped (r2 §3c). Tapping anywhere else opens the detail view. Off: the camera-off window with "Camera off", ○ OFF, and "Kitchen · 74°". There is no clock, because a clock on a one-row card answers nothing.

## 4. Idle home and Settings

- Centred clock and date (June page 1, r1 §1). No hint text.
- **Tiles**: dark glass at June's proportion (1.16 : 1, r1 §1 107 × 92). The glyph *is* the heating element (r1 §2 "Iconography"): Bake = bottom bar, Broil = top bar, Roast = both, and so on. At rest the glyph is a dim, unlit ember, so the card stays calm. On hover or focus it lights up like June's tile (bloom, gold core), the way the oven's screen "wakes when touched" (r1: "nearly invisible until you start interacting"). This is my own reconciliation of calm-at-rest (r2 §2 step 6) with June's glowing tiles.
- **Pages**: 13 items at 5 per page make 3 pages (Bake, Roast, Reheat, Broil, Toast / Air fry, Grill, Proof, Pizza, Dehydrate / Slow cook, Keep warm, **Settings**). The pager is a snap-scroller (`data-hx-scroll`) with a **tap alternative**: ‹ and › plus three dot buttons, all 48 × 48 (r2 §3a: ≤ 3 pages, the only paging system, only in Off). Equal gaps: one row per page, with the same gap between every tile.
- **Settings is a tile, not a circle.** It has the same shape as the mode tiles, as the lead asked, but a neutral grey gear with no ember and no glow. That keeps June's rule that warm colour means heat (r1 §2, §5.8). Circles would add a sixth shape type in Off.
- Tapping a tile opens Detail › Start for that mode. It never heats.

## 5. Quick add and the temperature graph

- **+1 / +5 / +10** is an outline chip group under the window. It appears only while a timer runs (cooking, door open, and dimmed when offline). It is separated from Stop in four ways: a different column, a different style (outline vs. red fill), a different alignment (left vs. centred), and a vertical offset. Stop never moves. r3 notes that no cook app verifiably places chips next to Stop, so this placement is our own choice. The story behind it: you look at the food in the window and decide it needs a little more. Done swaps the group for one button, **Keep baking…** (June's "Keep Roasting", r1 §1 Done). It opens the review because it heats again.
- **Graph**: Detail › Graph, opened by tapping the hero numeral or the Graph tab. It shows the oven line (ember), the food line (probe yellow), dashed target lines, and **door-open bands** drawn only from real door data, with the label "Door 1:24". The legend is also the set of line toggles, 48 px tall (Combustion/ThermoWorks, r3 §5.5). A plain-text summary under the graph states the door event. **No sparkline on the card.** None of the eight states needs one to answer its job (r2 §3b).

## 6. Several ovens

Multi mode = a standard door for the **focused** oven, plus one row per other oven above it (12 × 6).

- **Another oven heating** → a *strip*: the compact face (window + age, hero, status, a two-line **Stop / Garage** button). It is never hidden.
- **Another oven off** → a quiet 48 px *chip* ("○ Kitchen · Off"). It has no colour and no camera, so it reads as smaller and quieter (SHOULD).
- Tapping a strip or chip swaps that oven into the door. That is the switch between ovens (SHOULD).
- In multi mode every Stop names its oven ("Stop Kitchen", "Stop Garage"). Chip and Stop screen-reader labels always name the oven.
- The focused oven defaults to the first heating oven. With [Off Kitchen, preheating Garage], the Garage is in the door and the Kitchen is a chip. The card never opens on an idle oven while another one heats.
- Separate cards, one per oven, remain the default recommendation (r2 §3d).

## 7. Detail view (HA more-info style, 420 px, free height)

This is one level deep, with four tabs (**Now · Graph · History · Settings**) and a Stop that stays visible at the top while the oven heats. It is not a card paging system, because the dialog is a different surface.

- **Now**: the large 4:3 camera with "Watch live video · 5 min", then rows (≥ 56 px) for Oven temperature, Timer and Food probe target, each with a Change button that opens − / + steppers and a Set button. The Timer row is shown open.
- **Graph**: see §5.
- **History**: past cooks with their last frame, mode, time, length and door or food notes. Tapping one opens that cook's graph.
- **Settings**: alerts (Ready, Done / probe reached, Door left open, Not responding), camera (keep on while cooking, auto-off after 5 min), remote start (read-only: "changed only on the oven"), and oven info. Address and TLS are in HA › Devices.
- **Start** (from a tile, step 1 of 2): temperature, timer, food probe → **Review bake**.
- **Review** (step 2 of 2): a summary with the oven named; "This review expires at 6:35 PM"; the outcome-labelled **Start baking** (ember, the only warm button); Change; Cancel. Nothing heats before Start baking. Remote start is only offered for modes the oven allows (Bake/Roast proven). Other tiles open a Start page that says "Start Air fry on the oven", with no Start button.

| ready / done | #74D39A | #23703A | `color-mix(#35A55A 60 %, ink)` |
| door (warn) | #FFCB57 | #855600 | `color-mix(#D9981A 60 %, ink)` |

Measured contrast (node script): every text token is ≥ 5 : 1 on both the pane and the screen in Dark and Light. The Match-HA mixes are ≥ 4.5 : 1 on HA's default light and dark card colours, because mixing toward the theme's own text colour moves them the right way in either theme.

**How glass works in Light.** The metaphor is structural: one pane, two openings. It does not depend on black. In Light the pane is white, like a HA card, and the screen is a slightly recessed pale panel. The window stays dark because it is a view into a dark cavity, and a photograph keeps its own light. The result is that in Light the camera is the only dark thing on the card, which is honest and pleasant. Warm colour still means heat.

## 9. Typeface

**Barlow Condensed Light** for the hero numerals and the clock. **Barlow** (regular width, 400–700) for everything else. Both are SIL OFL and available from Google Fonts (a real build would bundle them, because HA often runs offline).

Why this family:
- Barlow is a low-contrast grotesk drawn from California road signs and plates. DIN comes from German road signage. That puts them in the same genre: engineered, slightly squared rounds, and a flat-sided "0".
- It ships the Light Condensed weight that June's thin hero numerals need (r1 §2 "Typography").
- **D-DIN**, the closest open DIN clone, has no Light weight. **Roboto Condensed** would feel HA-native but is humanist, not DIN.

Condensed type is used **only** for numerals. NN/g found condensed type 11 % slower in 1–2-word glances (r2 §1), so status words use regular-width Barlow in UPPERCASE, which that study found faster for short status words.

## 10. Accessibility

- Every target is ≥ 48 px: chips 48 × ≥ 48, Stop ≥ 48 high, pager buttons 48 × 48, tiles ≥ 52 px high including the label, detail rows ≥ 56 px, and the legend toggles 48 px. The compact card as a whole is the tap target for detail.
- Status always uses word, shape and colour: ○ Off, ↑ Preheating, ◉ Ready, ● Cooking, ▲ Door open, ✓ Done, ⊘ Offline (dashed and slashed). Each state has its own shape, so the states can be told apart in greyscale.
- Swipe is never the only way. Pager buttons, keyboard focus on the tiles, and `scroll-snap` are all available. No long-press, no drag.
- Reduced motion: the card has no animation at all. Page changes jump (`scrollLeft`, no smooth scroll). The only "motion" is the ack text changing.
- Screen readers: the root is `role=group`, labelled with the state sentence ("Kitchen oven: Cooking — 12 min left"). The progress rule is `role=img` with its own label ("Half of the 25 minute timer remains"). Chips say "Add 5 minutes to Kitchen timer". Stop says "Stop Kitchen oven". The ack line is `aria-live=polite`. Decorative SVGs are `aria-hidden`.
- Stale looks stale: the hero is dimmed to 45 %, the qualifier reads "as of 3 min ago", the rule turns grey, the window is greyed, and the status reads ⊘ OFFLINE. This degrades the hero itself (r2 §2 step 6), not just a footnote.
- Focus ring: a 2 px outline in the theme's focus colour, visible on dark glass.
